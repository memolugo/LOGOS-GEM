# LOGOS-GEM

Repositorio con los logos e imagenes de identidad de la **Agencia de Transformacion Digital (ATD)** y del **Gobierno del Estado de Morelos** que mas se usan en los proyectos locales, para poder referenciarlos por URL publica en archivos HTML (en vez de rutas locales tipo `file:///` o `../assets/...` que no se ven al compartir el archivo).

## Uso

Una vez publicado el repo en GitHub, cada imagen tiene una URL "raw" estable con este formato:

```
https://raw.githubusercontent.com/<usuario>/LOGOS-GEM/main/logos/<archivo>
```

Ejemplo en HTML:

```html
<img src="https://raw.githubusercontent.com/<usuario>/LOGOS-GEM/main/logos/isotipo-atd-solo.png" alt="ATD">
```

## Logos incluidos

| `logos/atd-logo-01.png` | Logo ATD usado en plantillas de informe y web del skill ATD |
